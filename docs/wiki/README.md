# Wiki do HealthPrior (fonte em `docs/wiki/`)

O repositório é privado e o plano da organização não oferece a aba Wiki do GitHub. Por isso estas páginas
ficam aqui, com nomes compatíveis com a wiki: se a Wiki for habilitada, basta copiar os arquivos para o
repositório `HealthPrior-time-branco.wiki.git` (`Home.md` vira a página inicial e `_Sidebar.md` o menu lateral).
Na wiki, remova a extensão `.md` dos links entre páginas; os links para `../` apontam para os documentos
do repositório e só funcionam aqui.

Comece por [Home](Home.md).
